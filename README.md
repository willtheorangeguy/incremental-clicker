## Key Features

- Stays on top of every other window, so the count is always visible.
- Increment, decrement, and reset.
- Tiny footprint — one small window, and 41 lines of source.
- No third-party dependencies; pure standard-library tkinter.
- A prebuilt Windows executable, for machines without Python.

## Installation

```bash
git clone https://github.com/willtheorangeguy/incremental-clicker.git
cd incremental-clicker
python clicker.py
```

Needs only Python with tkinter. See [`docs/installation.md`](docs/installation.md).

## Usage

Click to count. The window floats above everything else until you close it.
